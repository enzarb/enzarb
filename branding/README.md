# Enzarb Branding & Icon Set (`enzarb.dev`)

Complete original graphics, transparent cutouts, and rebuilt grid-locked SVG and raster branding set from the [Enzarb Branding & Website Plan Gemini conversation](https://share.gemini.google/3C1bQq64CvYC).

## Color Palette (Terminal Precision)

| Role | Color Name | Hex | Purpose / Usage |
| :--- | :--- | :--- | :--- |
| **Canvas (Dark)** | Deep Slate / Obsidian | `#0B0F17` | Primary background across docs, app, and landing page |
| **Surface** | Layered Navy Slate | `#131B2B` | Card containers, interactive panels, elevated code blocks |
| **Borders** | Muted Steel | `#232F46` | Subtle structural division lines and input borders |
| **Accent Primary** | Electric Cyan | `#00F0FF` | Primary CTA, active focus rings, cursor indicators, `E` mark & `.dev` |
| **Accent Secondary** | Laser Emerald | `#10B981` | Success states, uptime badges, speed metrics, `Z` mark |
| **Text Primary** | Crisp White | `#F8FAFC` | Primary headers, wordmark, and high-emphasis body text |
| **Text Secondary** | Muted Slate | `#94A3B8` | Subtitles, labels, descriptions, and metadata |

## Typography

- **Display / Headings & Body:** `Geist Sans`, `Inter`, or `Space Grotesk`
- **Code & Monospace:** `JetBrains Mono` or `Fira Code`
