# enzarb `operator/`

The `operator/` component of the enzarb monorepo (github.com/enzarb/enzarb). The repo root holds the architecture docs and shared conventions: see `../CLAUDE.md` and `../docs/architecture.md`. Releases are tagged `operator/vX.Y.Z`.

Run this component's own build/test commands from this directory. Changes to shared contracts (`proto/` frames, `workflows_api`/`app_api` schemas) must stay backward compatible.
